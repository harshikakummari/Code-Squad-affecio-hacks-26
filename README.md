# Beyond the Swipe 💗

### AFFECIO HACKS '26 — Team Code Squad

## 📌 About the Project

**Beyond the Swipe** is a compatibility-based social discovery platform designed to help people find meaningful connections beyond appearance. It focuses on shared interests, hobbies, music preferences, location, and personal goals to help users discover compatible people.

## ✨ Features

- **User Authentication:** Sign up and log in securely.
- **User Profiles:** Create profiles with personal details, bio, photo, interests, and preferred hobbies.
- **Preference Matching:** Consider users' interests and preferences when finding compatible profiles.
- **Compatibility Matching:** Help users discover people with common interests.
- **Profile Discovery:** View other users' profiles.

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **ODM:** Mongoose
- **Frontend:** EJS, HTML, CSS, JavaScript
- **Authentication:** Express Session, bcryptjs

## 🚀 Getting Started

### Prerequisites

- Node.js and npm
- MongoDB database

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/harshikakummari/Code-Squad-affecio-hacks-26.git
   ```

2. Navigate to the backend directory:

   ```bash
   cd Code-Squad-affecio-hacks-26/backend
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env` file inside the `backend` directory and configure your environment variables:

   ```env
   MONGODB_URI=your_mongodb_connection_string
   SESSION_SECRET=your_session_secret
   ```

5. Start the server using the command configured for your project:

   ```bash
   node server.js
   ```

6. Open the local URL shown in your terminal, usually `http://localhost:5000`.
